# Nivel 1: Registro por Consola (Validaciones Manuales)

Este es el proyecto más básico de la serie. Aquí aprendemos a validar la entrada de datos de un usuario directamente en un entorno de consola, usando sentencias condicionales simples (`if`/`else`).

## Qué Enseña este Nivel
1. **Validación de Presencia**: Asegurarse de que el usuario no envíe un campo vacío (o compuesto solo por espacios, usando `.trim()`).
2. **Validación de Longitud**: Validar que una cadena cumpla con un tamaño mínimo.
3. **Validación de Formato**: Validar la estructura de un correo electrónico usando una Expresión Regular (`RegEx`).
4. **Validaciones en Bucle**: Cómo pedir datos interactivamente hasta que la entrada sea correcta.

## Cómo Ejecutar el Proyecto
No requiere dependencias externas reales, pero se ha incluido un archivo `package.json` por consistencia.

Puedes ejecutar el proyecto con:
```bash
npm start
```
O directamente con:
```bash
node index.js
```
